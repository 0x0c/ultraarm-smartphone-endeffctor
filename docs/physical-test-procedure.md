# 実機での確認手順

印刷したアダプタを ultraArm P340 に付けて、モデルと自動テストでは確かめられない点を確かめる手順である。
仕様書の作業手順のうち、手順 4（試験片の確認）、手順 7（全体の確認）、手順 8 の残り（カメラ位置の実測）にあたる。

確認は次の順に進める。
前の段階で不合格になったら、パラメータを直して印刷し直し、その段階から再開する。

| 段階 | 内容 | 印刷するもの | 対応する仕様書の手順 |
|---|---|---|---|
| A | 受け口の磁石を確かめる | なし | 4 |
| B | 試験片で、はまり具合と吸着を確かめる | 試験片（約 11 g） | 4 |
| C | ホルダーを採寸する | なし | 7 の準備 |
| D | アダプタ全体を印刷して組み立てる | アダプタ（約 23 g） | 7 |
| E | 干渉、浮き上がり、まわり止め、水平を確かめる | なし | 7 |
| F | カメラ位置のオフセットを測る | なし | 8 |

各段階の結果は、末尾の[記録表](#記録表)に書き込む。
寸法の単位はすべて mm である。

## 用意するもの

- 部品表（`bom.csv`）の購入部品 4 点：スマホホルダー、1/4-20 のつまみねじ、ゴムワッシャ、鋼製の平行ピン（φ3×20）
- PETG フィラメントと 3D プリンタ
- ノギス、定規、さしがね（直角の定規）
- 鉄製のマイナスドライバー（磁石の確認に使う）
- 平らな金属板か厚めの定規（ピンの圧入に使う）
- 250 g 相当のおもり（スマホの代わりに使う。水を入れたペットボトルを養生テープでホルダーに留めてもよい）
- 方眼紙（A4 で 1 mm 方眼）とテープ、鉛筆
- スマホの水準器アプリとカメラアプリ（グリッド線を表示できるもの）
- アームの座標を読み、数値を指定して動かせる制御ソフト

## A. 受け口の磁石を確かめる

STEP には磁石そのものが含まれていないので、受け口に磁石が入っていることを先に確かめる。
磁石がなければ、試験片の鋼製ピンは意味を持たず、設計の前提から見直すことになる。

1. アームの電源を切った状態で、先端の受け口から純正の工具を抜く。
2. 鉄製のドライバーの先を、受け口の縦穴（幅 8、長さ 30 の穴）の底へ差し込む。
3. ドライバーの先が底に吸い付くかを確かめる。

**合格**：ドライバーが底に吸い付き、軽く引くと抵抗がある。

**不合格**：吸い付かない場合は、以降の段階に進まず結果を報告する。保持の方式（ラッチを足すなど）を設計し直す必要がある。

## B. 試験片で、はまり具合と吸着を確かめる

### 試験片を印刷する

1. リポジトリのルートで STL を書き出す。

   ```bash
   uv run python scripts/build.py
   ```

2. `build/coupon.stl` を、README の「印刷条件」に従って印刷する。PETG で、モデルの向きのまま底面を造形面に置く。サポートは要らない。
3. 造形面から外したら、舌片（縦穴に入る板）の底面と側面に糸引きやバリがないかを見て、あればカッターで落とす。
4. ノギスで舌片を測り、記録表に書く。設計値は次のとおりである。

   | 測る箇所 | 設計値 |
   |---|---|
   | 舌片の厚さ（前後） | 7.60 |
   | 舌片の幅（左右） | 29.60 |
   | 底面の溝の幅 | 2.90 |

   設計値から 0.1 以上ずれていたら、プリンタの寸法の癖として記録しておく。はまり具合の判定には実物を使うので、ここでは調整しない。

### 鋼製ピンを圧入する

1. 舌片の底面の溝へ、鋼製の平行ピンを置く。溝の長さは 20.4 で、ピンより少し長い。
2. 平らな金属板をピンに当て、ピンの表面が底面とそろうまで押し込む。手で押して入らなければ、作業台の上で板を当て、上から体重をかける。
3. 底面を上に向けて軽く振り、ピンが落ちないことを確かめる。

**合格**：ピンが底面とそろい、振っても落ちない。溝の縁が割れていない。

**不合格のときの調整**（`cad/params.py` の `steel_pin_press_fit`、初期値 0.1）：

| 症状 | 調整 |
|---|---|
| ピンが緩く、振ると落ちる | `steel_pin_press_fit` を 0.05 増やす（溝が狭くなる） |
| ピンが入らない、または溝の縁が割れる | `steel_pin_press_fit` を 0.05 減らす（溝が広くなる） |

緩いだけなら、溝に瞬間接着剤を少量入れてピンを留め、はまり具合の確認を先に進めてもよい。
その場合も、調整した値で次に印刷するものに反映する。

### 受け口に差し込む

1. アームの電源を切った状態で、試験片を受け口の真上に持ち、舌片を縦穴にまっすぐ下ろす。首（舌片と本体をつなぐ細い部分）は、受け口の前壁の切り欠きを通る。
2. 舌片が底まで入るかを見る。底に近づくと、磁石がピンを引き込む感触があるはずである。
3. 本体を前（ベースと反対の向き）へ指で押し、続けて左右に押して、がたつきを見る。
4. 真上に引き抜く。

**合格**：次の 4 点をすべて満たす。

- 工具を使わずに差し込め、途中で引っかからない。
- 底まで入り、磁石で引き込まれる。
- 前や左右へ指で押しても、がたつきを感じない。
- 真上に引けば、工具なしで抜ける。

**不合格のときの調整**（`cad/params.py` の `fit_clearance`、初期値 0.2、片側のすきま）：

| 症状 | 調整 |
|---|---|
| 入らない、途中で止まる | `fit_clearance` を 0.05 増やす |
| 入るが、前へ押すとがたつく | `fit_clearance` を 0.05 減らす |
| 底まで入るが、磁石で引き込まれない | 舌片が底に届いているかを見る。届いていればピンの圧入が浅い。ピンが底面より奥に沈んでいないかを確かめる |

値を変えたら、次のコマンドでモデルを作り直し、干渉テストが通ることを確かめてから試験片を印刷し直す。

```bash
uv run python scripts/build.py
uv run pytest
```

合格したら、そのときの `fit_clearance` と `steel_pin_press_fit` を記録表に書く。

## C. ホルダーを採寸する

アダプタの取り付け面にあるねじ穴の高さ（`screw_hole_height`、初期値 22.0）は仮の値である。
全体を印刷する前に、ホルダーの実物を測って確かめる。

1. ホルダーにスマホ（またはスマホと同じ厚さの板）を挟む。
2. 側面の 1/4 インチ穴を水平にし、スマホの背面が下を向くように机に置く。
3. 次の寸法を測り、記録表に書く。
   - **h**：側面の穴の中心から、スマホの背面までの高さ
   - **t**：側面の穴の雌ねじの深さ（ねじ込める長さ）
   - 側面の穴のまわりで、取り付け面に当たる平らな部分の大きさ（ゴムワッシャが載るか）

判定は次の 2 点である。

- **スマホの背面が受け口より下に出ないか**：ねじの軸は縦穴の上面から 4.1 上にあり、受け口の下面は縦穴の上面から 22.0 下にある。h が 26.1 を超えると、スマホの背面が受け口の下面より低くなり、アームを下げたときに受け口より先にスマホが机に当たる。撮影の高さを下げたい場合は、`screw_hole_height` を大きくしてねじの軸を上げる。
- **ねじの長さが足りるか**：つまみねじは、取り付け面の板（厚さ 5.0）とゴムワッシャ（厚さ約 1）を通ってからホルダーに入る。ホルダーに入る長さは「ねじ部の長さ − 6」で、2 以上かつ t 以下に収まる必要がある。収まらなければ、別の長さのねじを用意する。

`screw_hole_height` は、ねじ穴のまわりに 3 以上の肉を残すため、12.3 から 27.7 の範囲で変えられる。
この範囲を超える場合は、取り付け面の高さ（`mount_plate_height`）もあわせて変える必要があるので、結果を報告する。

## D. アダプタ全体を印刷して組み立てる

1. B と C で値を変えたら、`cad/params.py` を書き換え、`uv run pytest` が通ることを確かめる。
2. `uv run python scripts/build.py` で書き出した `build/adapter.stl` を、試験片と同じ条件で印刷する。外周 4 周以上、充填率 40％以上にする。
3. 取り付け面のねじ穴につまみねじを通してみる。上側が垂れて通らなければ、6.5 のドリルでさらう。
4. README の「組み立て」の手順 1〜3 に従い、ピンを圧入し、ホルダーを留める。ホルダーは、スマホを挟む面が水平になる向きで締める。
5. スマホを挟む前に、おもり（250 g 相当）をホルダーに留める。

## E. 実機で確かめる

この段階ではスマホを使わず、おもりを付けて試す。
外れたときに落ちても困らないよう、アームの下に厚手のタオルなどを敷く。

### 確かめる姿勢

制御ソフトで、次の 7 つの姿勢を順に指定する。
数値は、制御ソフトで動かせる範囲の端から少し内側にとる。
使った座標は記録表に書いておき、再試験のときも同じ座標を使う。

| 名前 | 位置 |
|---|---|
| P1 | 正面、中くらいの距離、中くらいの高さ |
| P2 | 正面、もっとも遠い距離 |
| P3 | 正面、もっとも近い距離 |
| P4 | ベースを左いっぱいに回した位置 |
| P5 | ベースを右いっぱいに回した位置 |
| P6 | もっとも低い位置（机に当たらない範囲） |
| P7 | もっとも高い位置 |

### 干渉

1. アダプタを装着し、低速で P1 から P7 まで順に動かす。
2. 移動中と各姿勢で、ホルダーやおもりが前腕や平行リンクに当たらないかを見る。

**合格**：どの姿勢でも、どの移動の途中でも当たらない。

### 浮き上がり

1. P1 で、制御ソフトで設定できる最大の速度にする。
2. P1 と P7 の間を、上下に 10 往復させる。
3. P2 と P3 の間を、前後に 10 往復させる。
4. 往復の途中と後で、差し込み部が受け口から浮いていないかを見る。本体と受け口の上面のすきまを目で見て、指で押し下げて沈むかを確かめる。

**合格**：浮かず、往復の後も底まで入ったままである。

**不合格**：浮いたときの速度と動きを記録表に書き、報告する。吸着材の量を増やす、梁を短くする、といった見直しが要る。

### まわり止め

1. 浮き上がりの試験の前に、ホルダーの横に養生テープを貼り、取り付け面との境目に鉛筆で線を引いておく。
2. 浮き上がりの試験に続けて、P4 と P5 の間を最大の速度で 10 往復させる。
3. 線がずれていないかを見る。

**合格**：線がずれていない。

**不合格**：ずれた量を記録表に書く。ねじの締め直しで止まらなければ、取り付け面に座ぐりを足す設計変更が要る。

### 水平

1. おもりを外し、スマホを画面を上にしてホルダーに挟む。
2. 水準器アプリを開き、P1 から P7 の各姿勢で、前後と左右の傾きを読む。

**合格**：すべての姿勢で、前後と左右の傾きが ±1° 以内である。

**不合格**：姿勢ごとの角度を記録表に書く。
すべての姿勢で同じ角度だけ傾くなら、ホルダーの締め付けの向きか、受け口自体の傾きによるものなので、ホルダーを締め直して再度測る。
姿勢によって角度が変わるなら、アームの先端が水平を保っていない。この場合は、仕様書の「カメラは真下」の前提を見直すことになる。

## F. カメラ位置のオフセットを測る

制御ソフトが報告する座標から、カメラの真下の点までのずれを測る。
アダプタの形から計算できる部分（ねじの軸まで前に 50.0、上に 4.1）は README にある。
しかし、アームの報告する座標が受け口のどの点を指すかは確かめられていない。
そこで、報告座標からカメラの真下の点までを、撮影した画像で直接測る。

座標は、制御ソフトの座標系に従う。
ベースの中心から正面に向かう向きを X、左に向かう向きを Y とし、ベースを回す角度を θ と書く。
制御ソフトの座標の向きがこれと違う場合は、記録表にその旨を書いておく。

### 方眼紙を置く

1. アームの正面、P1 の真下あたりの机に方眼紙をテープで固定する。以降、測り終えるまで方眼紙を動かさない。
2. カメラアプリでグリッド線を表示し、画面の中心（グリッド線の中央の交点）がわかるようにする。

### 机の高さを測る

1. 正面（Y = 0）で、アダプタの底面が方眼紙に触れる直前まで、制御ソフトで少しずつ下げる。
2. 底面と紙のすきまが 1 程度になったときの報告座標の Z を、記録表の **Zb** に書く。
3. 机からカメラのレンズまでの高さは、P1 などの高さで定規を当てて測り、そのときの報告座標の Z とあわせて記録表に書く。

撮影の高さは、報告座標の Z と Zb の差から求められる。

### 前後と左右のずれを測る

撮影に使う高さを 1 つ決め、以降の撮影はすべてその高さで行う。

1. 報告座標を (r1, 0) にして撮影し、画面の中心が指す方眼紙の点に印を付ける。この点を Q1 とする。
2. 報告座標を (r2, 0) にして同じく撮影し、印を付ける。r2 は r1 より 50 以上大きくとる。この点を Q2 とする。
3. 報告座標を、半径 r1 のまま θ = +30° と θ = −30° の位置にして撮影し、それぞれ印を付ける。座標は (r1 cos30°, r1 sin30°) と (r1 cos30°, −r1 sin30°) である。この 2 点を Q3、Q4 とする。

Q1、Q3、Q4 は、ベースの回転軸を中心とする円の上にある。
次の手順で、カメラのずれを求める。

1. Q1 と Q3 を結ぶ線分の垂直二等分線と、Q1 と Q4 を結ぶ線分の垂直二等分線を方眼紙に引く。2 本の交点 O が、ベースの回転軸の真下である。
2. Q1 から Q2 へ向かう向きが、アームの X の向きである。Q1 と Q2 の距離が r2 − r1 に一致することを確かめる（一致しなければ、カメラが水平でないか、撮影の高さがずれている）。
3. O から Q1 へのベクトルを、X の向きの成分 a′ と、それに直交する左向きの成分 b に分ける。
4. 前後のずれは a = a′ − r1、左右のずれは b である。

求めた a と b を記録表に書く。
報告座標が (x, y) のとき、カメラの真下の点は、ベースの回転角を θ として (x + a cosθ − b sinθ, y + a sinθ + b cosθ) にある。

## 結果を反映する

すべての段階が終わったら、次を行う。

1. `cad/params.py` を確定した値に書き換え、`uv run pytest` が通ることを確かめる。
2. README の「実機での確認」の表の結果欄を埋める。
3. README の「カメラ位置のオフセット」節に、a、b、Zb と、撮影の高さの求め方を書く。
4. 仕様書の手順 4、7、8 に ✅ を付け、ステータスを「実装完了」にする。

記録表を Claude に渡せば、上の 4 点の書き換えと、プランのページの更新をまとめて頼める。
