# スマホホルダー用エンドエフェクタ

> ステータス: ドラフト
> 対象: ultraArm P340 の先端に装着する 3D プリント部品（`cad/`）
> 関連: [ultraArm P340 製品仕様](https://docs.elephantrobotics.com/docs/ultraArm-en/1-BriefIntroduction/2-Product/1-UltraArmP340/1-IntroductionToProductParameters.html)、[スマホホルダー商品ページ](https://www.amazon.co.jp/dp/B00WILM97G)

Elephant Robotics の ultraArm P340 の先端にあるクイックチェンジ式の受け口へ差し込み、市販のスマホホルダーを 1/4 インチねじで固定するアダプタを作る。
スマホは画面を上にして水平に寝かせ、背面カメラで真下を撮る。
形状は CadQuery（Python で書く CAD ライブラリ）のコードで定義し、公式の STEP モデルから受け口の寸法を読み取って設計する。

## 1. なにをつくるのか

完成したアダプタは、純正のペンホルダーや吸着ポンプと同じ手順で、アームの先端に差し込むだけで装着できる。
装着後、アダプタの先にスマホホルダーをねじ 1 本で取り付け、スマホを挟む。
スマホはアームの先端からベースと反対の方向（前方）へ張り出し、画面を上、背面カメラを下に向けて水平に保たれる。
アームを動かすと、スマホは姿勢を保ったまま机の上を平行移動し、真下を撮影できる。

対象とする部品と前提は次のとおりである。

- **ロボットアーム**：Elephant Robotics ultraArm P340。可搬重量は 650 g、作業半径は 340 mm である。
- **スマホホルダー**：Dhana Style の 2-Way スマホホルダー（ASIN B00WILM97G）。背面と側面に 1/4 インチの雌ねじを持ち、重さは約 25 g、対応するスマホ幅は約 62〜90 mm である。
- **スマホ**：機種を限定しない。重さは最大 250 g を想定する。
- **製作**：手元の FDM 方式の 3D プリンタで印刷する。

成果物は次の 4 つである。

- CadQuery で書いたアダプタのモデル（寸法はすべてパラメータとして先頭にまとめる）
- 印刷用の STL と、確認用の STEP
- 受け口との干渉と、印刷可能な大きさに収まることを確かめる自動テスト
- 組み立て手順と、アームの先端から見たカメラ位置のずれ（オフセット）を記した README

### やらないこと

- **4 軸目のクイックチェンジサーボへの対応**：先端を回す純正アクセサリは使わない。サーボを介すと出力軸の寸法とトルクの検討が別に要り、剛性も落ちる。スマホの向きはベースの回転（J1）に従えば撮影の用途には足りる。
- **カメラの角度調整機構**：真下に固定する。チルト用のヒンジは部品が増え、がたつきの原因になる。斜めから撮る必要が出たら、角度違いの部品を別に起こす。
- **アームの制御ソフトウェア**：カメラ位置のオフセット値を README に記すところまでとし、座標変換や撮影を自動化するプログラムは作らない。
- **スマホホルダー自体の改造や自作**：市販品をそのまま使う。

## 2. なぜつくるのか

ultraArm P340 の先端は、ねじ穴で部品を留める方式ではない。
先端は上面に縦穴の開いた受け口で、工具の舌片を上から差し込み、磁石で吸着させて保持する構造（公式の呼称は「EasyConnect」）になっている。
純正の工具はペン、レーザー、グリッパー、吸着ポンプ、4 軸目のサーボ、レゴ用フランジに限られ、カメラやスマホを付ける部品は用意されていない。

一方で、スマホホルダーの側は写真用品の標準である 1/4 インチねじ（1/4-20 UNC）で固定する。
ロボットの受け口と写真用品のねじは規格がまったく異なり、間をつなぐ部品が市販されていないので、自分で作るほかない。

スマホをアームに載せられると、机の上の物や書類を、決まった高さと位置から繰り返し真下に撮影できる。
手で構えた撮影と比べると、撮影位置がプログラムで再現できる点が違う。
連続撮影やタイムラプス、複数枚の画像のつなぎ合わせで、撮影位置の再現性が効いてくる。

アダプタがない現状では、テープや結束バンドで仮止めするしかない。
仮止めはアームを動かすたびにスマホの姿勢がずれ、撮影位置が再現できない。
さらに、可搬重量の上限に近い 250 g 級のスマホを前方へ張り出して固定すると、先端にかかるモーメントで受け口から外れ、スマホを落とすおそれがある。

## 3. どう実現するか

### 全体構成

アダプタは 1 つの印刷部品と、市販の締結部品からなる。

```mermaid
flowchart LR
  A[ultraArm P340 先端の受け口] -- 上から差し込み、磁石で吸着 --> B[差し込み部]
  B --- C[前方へ伸びる梁]
  C --- D[ホルダー取り付け面]
  D -- 1/4-20 つまみねじとゴムワッシャ --> E[スマホホルダーの側面の穴]
  E -- クランプ --> F[スマホ 画面が上、カメラが下]
```

印刷部品は、次の 3 つの区画を一体で造形したものである。

| 区画 | 役割 | 寸法の決め方 |
|---|---|---|
| 差し込み部 | 受け口の縦穴に入る舌片と、前壁の切り欠きを通る首からなる。縦穴への差し込みと磁石の吸着で保持される | 公式 STEP から受け口の内形を測り、すきまを足して決める |
| 梁 | 差し込み部から前方へ伸び、スマホがアームの前腕に当たらない位置まで張り出す | 前腕との干渉と、モーメントの大きさの兼ね合いで決める |
| ホルダー取り付け面 | 梁の先端で鉛直に立つ板。1/4 インチのねじを通す穴を持つ | ホルダーの側面の穴の位置と、つまみねじの長さで決める |

### スマホの向きと、側面の穴を使う理由

ホルダーには背面と側面に 1/4 インチの穴がある。
背面の穴はスマホの背面側、つまりカメラ側にある。
カメラを真下に向けると背面の穴も下を向き、アダプタがスマホと机の間に入り込んでしまう。
そこで側面の穴を使う。
側面の穴にねじを水平に通すと、ホルダーはスマホを水平に寝かせた姿勢で保持され、アダプタはスマホの縁の外側に収まる。

ねじの軸はアームの前方を向き、スマホの幅方向（62〜90 mm）が前方へ、長辺方向が左右へ広がる。
カメラはスマホの長辺の端にあるので、アームの中心線から左右に数十 mm ずれる。
このずれは README に計測値として記載し、制御側で補正できるようにする。

### 締結とまわり止め

ホルダーの固定には、市販の 1/4-20 UNC のつまみねじ（カメラ用の D リング付きねじなど）を使う。
1/4 インチのねじを FDM で直接印刷すると、ねじ山がつぶれやすく、締め付けに耐えない。
つまみねじは取り付け面の貫通穴（直径 6.6 mm 程度）に通し、ホルダーの雌ねじにねじ込む。

ねじ 1 本で留めると、ホルダーがねじの軸のまわりに回りうる。
スマホの重心はねじの軸の近くにあるため、重力による回転トルクは小さい。
それでも、アームの加減速で回らないように、取り付け面とホルダーの間に薄いゴムワッシャを挟み、摩擦で止める。
試作でまわり止めが足りないと判明した場合は、取り付け面にホルダーの外形に沿う浅い座ぐりを設け、形状で回転を止める。

### 先端の受け口との結合

受け口の寸法は、公式の STEP モデルから CadQuery のスクリプトで読み取った。
STEP の入手先は README に記した。
計測値の詳細は README の「計測値」節にあり、設計に効くのは次の点である。

- 受け口の上面に、幅 8.00 mm（前後）、長さ 30.00 mm（左右）、深さ 17.90 mm の縦穴が開いている。縦穴の鉛直の稜は 1 mm の面取りで埋まっている。
- 受け口の前壁（厚さ 5.80 mm）には、縦穴の左右中央に幅 8.00 mm の切り欠きが、縦穴の底まで通っている。
- 縦穴の底の裏側に磁石を収める凹みがあり、縦穴の底との肉厚は 0.50 mm である。磁石は受け口の側にある。
- ラッチはない。工具は縦穴への差し込みと、磁石の吸着と、自重で保持される。

差し込み部は、この形に合わせて 3 つの部分で構成する。
縦穴に入る板状の舌片、前壁の切り欠きを通る首、受け口の前面の外側に出る本体である。
装着は、差し込み部を受け口の真上から下ろして行う。
舌片の四隅の鉛直の稜は、縦穴の面取りに当たらないよう、面取りとすきまの和より大きく面取りする。

磁石は受け口の側にあるので、差し込み部には磁石に吸着する鋼材を入れる。
吸着材には、入手しやすい鋼製の平行ピン（直径 3 mm、長さ 20 mm）を使う。
磁石の凹み（幅 4 mm、長さ 22 mm）と同じ向きに、舌片の底面へピンを圧入する溝を設け、ピンの表面を舌片の底面とそろえる。
ステンレス（SUS304 など）のピンは磁石に付かないので使わない。

STEP の読み取り値は実機で確かめる。
差し込み部だけの試験片を印刷し、受け口への挿入と吸着を確かめてから、梁を含む全体を印刷する。

### 荷重と強度の見積もり

想定する最大の負荷は、250 g のスマホとホルダー（約 25 g）である。
アダプタの重さを 30 g 程度に抑えれば、合計は約 305 g で、可搬重量 650 g の半分に収まる。

注意すべきは重さより、前方へ張り出すことで先端にかかるモーメントである。
受け口からスマホの重心までの水平距離を 80 mm とすると、モーメントは 0.305 kg × 9.8 m/s² × 0.08 m ≒ 0.24 N·m になる。
このモーメントは、舌片の上端を縦穴の前壁へ、下端を後壁へ押し付ける向きに働く。
縦穴は深さ 17.90 mm あるので、舌片は 2 つの壁から受ける反力の組でモーメントへ抵抗するので、磁石の吸着力は要らない。
一方で、差し込み部を真上へ引き抜く力に抵抗するのは、磁石の吸着力と自重だけである。
アームを急に上下させたときに差し込み部が浮かないかは、実機で確かめる。
張り出しの長さは、前腕との干渉を避けられる範囲で最短にする。

### 先端の姿勢の前提

本設計は、アームの先端が姿勢によらず水平を保つことを前提とする。
STEP モデルのリンク構成から、受け口は肘の部品と平行四辺形リンクでつながり、肘の部品も上腕と平行なリンクで姿勢を保つ構成であることを確かめた。
ただし、肘の部品を支えるリンクの下端が回転台に固定されていることは STEP の中で特定できていない。
実機でも水平が保たれることを確かめ、保たれない場合は、本仕様の「カメラは真下」の前提を見直す。

### CAD と生成物の構成

リポジトリの構成は次のとおりとする。

| パス | 内容 |
|---|---|
| `cad/params.py` | 寸法パラメータ。受け口のすきま、梁の長さ、肉厚、ねじ穴径などを 1 か所にまとめる |
| `cad/adapter.py` | パラメータからアダプタの形状を組み立てる |
| `cad/coupon.py` | 差し込み部だけの試験片を作る |
| `scripts/inspect_step.py` | 公式 STEP を読み、受け口の内形の寸法を出力する |
| `scripts/build.py` | STL と STEP を `build/` に書き出す |
| `tests/` | pytest による自動テスト |
| `vendor/` | 公式 STEP の置き場。再配布の条件が不明なので Git の管理に含めない |
| `README.md` | 組み立て手順、印刷条件、カメラ位置のオフセット |

`cad/params.py` の主なパラメータは次のとおりである。
値は STEP の計測と試作で確定させ、本仕様では初期値だけを示す。

| 名前 | 型 | 初期値 | 意味 |
|---|---|---|---|
| `fit_clearance` | `float` | `0.2` | 受け口と差し込み部の片側のすきま（mm） |
| `beam_length` | `float` | `60.0` | 差し込み部の前端からホルダー取り付け面までの水平距離（mm） |
| `beam_thickness` | `float` | `6.0` | 梁の厚さ（mm） |
| `mount_plate_thickness` | `float` | `5.0` | ホルダー取り付け面の板厚（mm） |
| `screw_hole_diameter` | `float` | `6.6` | 1/4 インチのつまみねじを通す穴の径（mm） |
| `steel_pin_diameter` | `float` | `3.0` | 舌片の底に圧入する鋼製の平行ピンの径（mm） |
| `steel_pin_length` | `float` | `20.0` | 同じく平行ピンの長さ（mm） |
| `steel_pin_press_fit` | `float` | `0.1` | ピンを圧入するための溝幅の詰め代（mm）。試作で決める |

### 印刷条件

材料は PETG を基本とする。
PLA は夏場の室温や直射日光で変形しやすく、ゴムワッシャを締め付けた取り付け面はクリープするおそれもある。
梁は曲げを受けるので、積層方向が曲げの向きと直交するように、梁を水平に寝かせた向きで印刷する。

### テスト

自動テストは次の 3 点を確かめる。
実機での確認は自動化できないので、作業手順で別に立てる。

- アダプタの形状が単一の閉じた立体として生成される。
- 公式 STEP の受け口に差し込み部を配置したとき、干渉する体積がゼロである（`vendor/` に STEP がない環境ではスキップする）。
- 部品全体が一般的な FDM プリンタの造形範囲（200 mm 角）に収まる。

## 4. 検討した代替案と、採らなかった理由

| 案 | 概要 | 採らなかった理由 |
|---|---|---|
| ホルダーの背面の穴で留める | ホルダーの背面にねじを通し、スマホを吊り下げる | カメラを真下に向けると背面の穴も下を向き、アダプタがスマホと机の間に入り込む。カメラを前方へ向ける用途なら背面の穴が自然なので、その場合はこの案に切り替える |
| 4 軸目のサーボを介して取り付ける | 純正のクイックチェンジサーボの出力軸にホルダーを付け、スマホを回せるようにする | サーボ出力軸の寸法とトルクの検討が別に必要になり、結合部が増えて剛性も落ちる。真下の撮影ではベースの回転で向きを変えれば足りる |
| 純正のレゴ用フランジと市販品を組み合わせる | 印刷せず、レゴ用フランジに 1/4 インチのボルトやプレートを組み合わせる | 部品の組み合わせでスマホの向きと張り出し方向を自由に決められず、結合部が多くてがたつく |
| チルト可能なヒンジを設ける | 取り付け面を蝶番にして、カメラの角度を変えられるようにする | 用途が真下の撮影に定まっており、可動部はがたつきと部品点数の増加を招く |
| スマホを先端の真横へ張り出す | 梁を左右方向へ伸ばす | 前方への張り出しは短くなるが、ベースを回したときにカメラの位置が先端を中心とする円弧を描き、撮影位置の計算が複雑になる |
| スマホを先端の真下に吊る | 梁を設けず、先端の直下にホルダーを付ける | 重心は安定するが、先端の真下に最大 90 mm 幅の板が来るため、アームを低い位置まで下げられず、撮影の高さの範囲が狭まる |
| 1/4 インチのねじ山を印刷する | 市販のねじを使わず、雄ねじを部品と一体で印刷する | FDM のねじ山は強度と精度が足りず、締め付けでつぶれる |
| OpenSCAD で書く | CadQuery の代わりに OpenSCAD でモデルを書く | OpenSCAD は STEP を読めず、受け口の寸法の読み取りと干渉テストを別のツールで行う必要がある |
| GUI の CAD（Fusion など）で作る | 手作業でモデリングする | 寸法の変更履歴を Git で追えず、パラメータを変えて作り直す手間が大きい |
