# ultraArm P340 スマホホルダー用エンドエフェクタ

Elephant Robotics の ultraArm P340 の先端に差し込み、市販のスマホホルダー（Dhana Style 2-Way）を取り付けるアダプタの CAD モデルである。
スマホは画面を上にして水平に寝かせ、背面カメラで真下を撮る。
設計の経緯と作業手順は [仕様書](docs/specs/smartphone-holder-adapter.md) にある。

## 開発環境

[uv](https://docs.astral.sh/uv/) で Python 3.12 と CadQuery を用意する。

```bash
uv sync
uv run pytest
```

公式の STEP モデルは再配布の条件が不明なので、リポジトリには含めない。
次の URL から取得し、`vendor/` に置く。

```bash
curl -fL -o vendor/UltraArm_P340_3D_230918.stp \
  https://download.elephantrobotics.com/Product_3d_files/230918/UltraArm_P340_3D_230918.stp
```

## 計測値

公式 STEP（`UltraArm_P340_3D_230918.stp`、2022-12-15 作成）から、`scripts/inspect_step.py` で読み取った値である。
同じ値は次のコマンドで再現できる。

```bash
uv run python scripts/inspect_step.py
```

### 座標系

STEP の座標系は Z 軸が上を向く。
ベースは +X 側にあり、アームは -X 方向へ伸びている。
以下では、-X 方向（ベースから遠ざかる向き）を「前」と呼ぶ。
STEP の姿勢では上腕が鉛直、前腕が水平で、受け口は前腕の先端にある。

### 先端の受け口

受け口は上面に開いた縦穴を持ち、工具の舌片を上から差し込んで保持する。
前壁には縦穴の底まで達する切り欠きがあり、舌片と受け口の外側にある工具本体は、この切り欠きを通る首でつながる。

| 項目 | 値（mm） | STEP 上の範囲 |
|---|---|---|
| 縦穴の幅（前後方向、X） | 8.00 | X −93.51〜−85.51 |
| 縦穴の長さ（左右方向、Y） | 30.00 | Y −63.09〜−33.09 |
| 縦穴の深さ（Z） | 17.90 | 底 Z 162.10、上面 Z 180.00 |
| 縦穴の角の面取り | 1.0（45°） | 鉛直の稜と上面の縁 |
| 前壁の厚さ | 5.80 | 前面 X −99.31 から縦穴まで |
| 前壁の切り欠きの幅（Y） | 8.00 | Y −52.09〜−44.09（縦穴の中央） |
| 前壁の切り欠きの高さ | 17.90 | 縦穴と同じく Z 162.10〜180.00 |
| 受け口の外形（ピンの突起を除く） | 49.4 × 44.5 × 22.0 | X −99.31〜−49.87、Y −69.84〜−25.34、Z 158.00〜180.00 |

公式図面の寸法（幅 30、スロット 8、奥行き 17.9）は、縦穴の長さ、幅、深さにそれぞれ一致する。

### 磁石による吸着

受け口の下面には、縦穴の真下に凹み（X 4.00 × Y 22.00 × 深さ 3.60）が掘り込まれている。
凹みの天井から縦穴の底までの肉厚は 0.50 mm しかない。
公式図面が「Magnetic absorption area」と示す位置と一致するので、磁石は受け口の側にあり、凹みに収められていると判断した。
したがって、工具の側の舌片の底には、磁石に吸着する鋼板などを入れれば足りる。

ただし STEP には磁石そのものが含まれていない。
実機で縦穴の底に鉄製のドライバーなどを近づけ、吸着することを確かめる必要がある。

### ラッチの有無

受け口にラッチの構造は見当たらない。
公式図面の側面図でフック状に見える部分は、平行リンクのピンを受ける突起である。
工具は、縦穴への差し込みと、磁石の吸着と、自重で保持される。

### 先端が水平を保つか

受け口は 2 本のピンでアームにつながる。
1 本は前腕の先端（X −58.51、Z 169.00）、もう 1 本は平行リンクの棒（X −73.51、Z 189.00）である。
肘の部品（立体 #12）も同じ相対位置（X 方向に −15、Z 方向に +20）に 2 本のピンを持ち、受け口のピンとの距離はどちらも 140.00 mm である。
4 本のピンが平行四辺形をなすので、受け口は肘の部品と常に同じ姿勢に保たれる。

肘の部品はさらに、リンク #15 で土台の側（X 100.06、Z 46.43）につながる。
リンク #15 の長さは 130.00 mm で、上腕のピン間（Z 39.00 から 169.00）と等しく、互いに平行である。
したがって、肘の部品も上腕との平行四辺形で姿勢を保つ構成になっている。
ただし、リンク #15 の下端を受ける部品が J1 の回転台に固定されていることは、STEP の中で特定できなかった。
以上から、先端は姿勢によらず水平を保つと判断する。
最終的な確認は、実機でスマホの水準器アプリを使って行う。
