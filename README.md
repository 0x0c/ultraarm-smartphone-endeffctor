# ultraArm P340 スマホホルダー用エンドエフェクタ

Elephant Robotics の ultraArm P340 の先端に差し込み、市販のスマホホルダー（Dhana Style 2-Way）を取り付けるアダプタの CAD モデルである。
スマホは画面を上にして水平に寝かせ、背面カメラで真下を撮る。
設計の経緯と作業手順は [仕様書](docs/specs/smartphone-holder-adapter.md) にある。

## 開発環境

[uv](https://docs.astral.sh/uv/) で Python 3.12 と CadQuery を用意する。

```bash
uv sync
uv run pytest
```

公式の STEP モデルは再配布の条件が不明なので、リポジトリには含めない。
次の URL から取得し、`vendor/` に置く。

```bash
curl -fL -o vendor/UltraArm_P340_3D_230918.stp \
  https://download.elephantrobotics.com/Product_3d_files/230918/UltraArm_P340_3D_230918.stp
```

## 残作業の管理

残りの作業は、`task` ラベルを付けた [GitHub Issue](https://github.com/0x0c/ultraarm-smartphone-endeffctor/issues?q=is%3Aissue+label%3Atask) で管理している。
各 Issue の本文に完了条件と前提の Issue があり、実機で確かめた結果はその Issue にコメントで書く。
Claude Code では `/start-issue` で、着手できる Issue を選んで担当を付け、作業ブランチを切ってから作業を始められる。

## 部品表

必要な部品、材料、工具は [`bom.csv`](bom.csv) にまとめてある。
購入が必要なのは次の 4 点である。

- スマホホルダー Dhana Style 2-Way（ASIN B00WILM97G）
- 1/4-20 UNC のつまみねじ（ねじ部の長さ 8〜10 mm）
- ゴムワッシャ（内径 6.5 mm 前後、厚さ 1 mm 程度）
- 鋼製の平行ピン（直径 3 mm、長さ 20 mm）。ステンレス（SUS304 など）は磁石に付かないので使わない

## 印刷条件

- **材料**：PETG。PLA は夏場の室温や直射日光で変形しやすく、ゴムワッシャを締め付けた取り付け面がクリープするおそれもある。
- **向き**：モデルの向きのまま、底面（舌片、梁の底）を造形面に置く。底面は 1 つの平面にそろえてあり、サポートは要らない。
- **ねじ穴**：取り付け面のねじ穴は水平に印刷される。上側がわずかに垂れたら、6.5 mm のドリルでさらう。
- **充填**：外周 4 周以上、充填率 40％以上を目安にする。充填率 100％でも約 23 g である。

印刷用のファイルは次のコマンドで `build/` に書き出す。

```bash
uv run python scripts/build.py
```

`build/coupon.stl` は差し込み部だけの試験片である。
全体を印刷する前に試験片で受け口へのはまり具合を確かめ、必要なら `cad/params.py` の `fit_clearance` を調整する。

## 組み立て

1. アダプタの舌片の底にある溝へ、鋼製の平行ピンを押し込む。ピンの表面が底面とそろうまで、平らな板を当てて押す。
2. 取り付け面の後ろから、つまみねじをねじ穴に通す。取り付け面の前側にゴムワッシャを通す。
3. ホルダーの側面の穴にねじをねじ込み、スマホを挟む面が水平になる向きで締める。スマホの画面が上、背面カメラが下を向く。
4. アダプタを受け口の真上から下ろし、舌片を縦穴に差し込む。磁石で底まで引き込まれる。
5. ホルダーにスマホを挟む。

取り外すときは、アダプタを真上に引き抜く。

## 実機での確認

印刷したアダプタを装着し、次の項目を確かめる。結果は本節に追記する。
試験片の印刷からカメラ位置の実測までの詳しい手順と記録表は、[実機での確認手順](docs/physical-test-procedure.md) にある。

| 項目 | 確かめ方 | 結果 |
|---|---|---|
| 受け口の磁石 | 縦穴の底に鉄製のドライバーを近づけ、吸着することを確かめる | 未確認 |
| 試験片のはまり具合 | 工具なしで抜き差しでき、磁石で底まで引き込まれ、前に押してもがたつかない | 未確認 |
| 浮き上がり | 250 g 相当（スマホまたはおもり）を付け、アームを最大速度で上下させても差し込み部が浮かない | 未確認 |
| ホルダーのまわり止め | 同じ負荷で作業範囲の端から端まで動かしても、ホルダーがねじの軸のまわりに回らない | 未確認 |
| 干渉 | 作業範囲の全域で、スマホとホルダーが前腕や平行リンクに当たらない | 未確認 |
| 水平 | スマホの水準器アプリで、作業範囲の各所で画面が水平（±1° 以内）である | 未確認 |

## カメラ位置のオフセット

アームの座標から撮影位置を決めるには、受け口からカメラまでのずれ（オフセット）が要る。
オフセットは、アダプタの形から決まる部分と、ホルダーとスマホの寸法で決まる部分の和になる。

アダプタの形から決まる部分は、縦穴の上面の中心からホルダーを留めるねじの軸までである。
`cad/params.py` の値から計算した結果は次のとおりで、パラメータを変えると値も変わる。

| 方向 | 縦穴の上面の中心からねじの軸まで（mm） |
|---|---|
| 前後（前が正） | +50.0（取り付け面の前面） |
| 左右 | 0.0 |
| 上下（上が正） | +4.1 |

ホルダーとスマホの寸法で決まる部分は、まだ実測していない。
ホルダーを留めた状態で、ねじの軸から背面カメラのレンズ中心まで、前後、左右、上下のずれを測り、上の値に足す。
スマホの機種を替えたら測り直す。

アームの報告する座標が受け口のどの点を指すかは、公式の文書から確かめられていない。
アームを既知の位置に動かし、受け口の縦穴の上面の中心が報告座標からどれだけずれるかを測って、オフセットに加える。

## 計測値

公式 STEP（`UltraArm_P340_3D_230918.stp`、2022-12-15 作成）から、`scripts/inspect_step.py` で読み取った値である。
同じ値は次のコマンドで再現できる。

```bash
uv run python scripts/inspect_step.py
```

### 座標系

STEP の座標系は Z 軸が上を向く。
ベースは +X 側にあり、アームは -X 方向へ伸びている。
以下では、-X 方向（ベースから遠ざかる向き）を「前」と呼ぶ。
STEP の姿勢では上腕が鉛直、前腕が水平で、受け口は前腕の先端にある。

### 先端の受け口

受け口は上面に開いた縦穴を持ち、工具の舌片を上から差し込んで保持する。
前壁には縦穴の底まで達する切り欠きがあり、舌片と受け口の外側にある工具本体は、この切り欠きを通る首でつながる。

| 項目 | 値（mm） | STEP 上の範囲 |
|---|---|---|
| 縦穴の幅（前後方向、X） | 8.00 | X −93.51〜−85.51 |
| 縦穴の長さ（左右方向、Y） | 30.00 | Y −63.09〜−33.09 |
| 縦穴の深さ（Z） | 17.90 | 底 Z 162.10、上面 Z 180.00 |
| 縦穴の角の面取り | 1.0（45°） | 鉛直の稜と上面の縁 |
| 前壁の厚さ | 5.80 | 前面 X −99.31 から縦穴まで |
| 前壁の切り欠きの幅（Y） | 8.00 | Y −52.09〜−44.09（縦穴の中央） |
| 前壁の切り欠きの高さ | 17.90 | 縦穴と同じく Z 162.10〜180.00 |
| 受け口の外形（ピンの突起を除く） | 49.4 × 44.5 × 22.0 | X −99.31〜−49.87、Y −69.84〜−25.34、Z 158.00〜180.00 |

公式図面の寸法（幅 30、スロット 8、奥行き 17.9）は、縦穴の長さ、幅、深さにそれぞれ一致する。

### 磁石による吸着

受け口の下面には、縦穴の真下に凹み（X 4.00 × Y 22.00 × 深さ 3.60）が掘り込まれている。
凹みの天井から縦穴の底までの肉厚は 0.50 mm しかない。
公式図面が「Magnetic absorption area」と示す位置と一致するので、磁石は受け口の側にあり、凹みに収められていると判断した。
したがって、工具の側の舌片の底には、磁石に吸着する鋼板などを入れれば足りる。

ただし STEP には磁石そのものが含まれていない。
実機で縦穴の底に鉄製のドライバーなどを近づけ、吸着することを確かめる必要がある。

### ラッチの有無

受け口にラッチの構造は見当たらない。
公式図面の側面図でフック状に見える部分は、平行リンクのピンを受ける突起である。
工具は、縦穴への差し込みと、磁石の吸着と、自重で保持される。

### 先端が水平を保つか

受け口は 2 本のピンでアームにつながる。
1 本は前腕の先端（X −58.51、Z 169.00）、もう 1 本は平行リンクの棒（X −73.51、Z 189.00）である。
肘の部品（立体 #12）も同じ相対位置（X 方向に −15、Z 方向に +20）に 2 本のピンを持ち、受け口のピンとの距離はどちらも 140.00 mm である。
4 本のピンが平行四辺形をなすので、受け口は肘の部品と常に同じ姿勢に保たれる。

肘の部品はさらに、リンク #15 で土台の側（X 100.06、Z 46.43）につながる。
リンク #15 の長さは 130.00 mm で、上腕のピン間（Z 39.00 から 169.00）と等しく、互いに平行である。
したがって、肘の部品も上腕との平行四辺形で姿勢を保つ構成になっている。
ただし、リンク #15 の下端を受ける部品が J1 の回転台に固定されていることは、STEP の中で特定できなかった。
以上から、先端は姿勢によらず水平を保つと判断する。
最終的な確認は、実機でスマホの水準器アプリを使って行う。
